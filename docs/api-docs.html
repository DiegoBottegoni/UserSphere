Auth

POST /auth/register Public
Register a new user account.
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "securePassword123"
}
POST /auth/login Public
Login with email and password. Sets accessToken and refreshToken cookies.
{
  "email": "john@example.com",
  "password": "securePassword123"
}
GET /auth/google Public
Initiates Google OAuth2 flow. Redirects user to Google login page.
POST /auth/refresh Cookie: refreshToken
Refresh expired access token using the httpOnly refresh token cookie.
GET /auth/me Protected
Get currently logged-in user profile.
POST /auth/logout Protected
Logs out user and clears cookies.

Users

GET /users/ Protected ADMIN
Retrieve a list of all registered users. Restricted to Administrators.
GET /users/:id Protected
Get public profile details of a specific user.
POST /users/ Protected
Create a new user manually (Admin/Internal use). Normal users should use /auth/register.
PUT /users/:id Protected
Update user profile details.
{
  "name": "John Updated",
  "isOnline": true
}
DELETE /users/:id Protected ADMIN
Permanently delete a user account. Restricted to Administrators.

Friendships

POST /friendships/:receiverId Protected
Send a friendship request to another user.
GET /friendships/pending Protected
Get all received friendship requests with status PENDING.
GET /friendships/pending/sent Protected
Get all sent friendship requests with status PENDING.
GET /friendships/ Protected
List all confirmed friends (Status ACCEPTED).
PUT /friendships/:friendshipId/accept Protected
Accept a received friendship request.
PATCH /friendships/:friendshipId/reject Protected
Reject a friendship request.
PATCH /friendships/:friendshipId/block Protected
Block a user (via their friendship ID).

Messages

POST /messages/ Protected
Send a private message to another user.
{
  "receiverId": "uuid-here",
  "content": "Hello world!"
}
GET /messages/last Protected
Get the last message for each conversation (Inbox view).
GET /messages/:otherUserId Protected
Get full conversation history with a specific user.
PATCH /messages/:messageId/read Protected
Mark a specific message as read.
DELETE /messages/:messageId Protected
Delete a message (soft or hard delete depending on implementation).
